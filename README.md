# Do que se trata???

É um balanço financeiro geral da empresa para descobrir qual vendedor obteve o melhor reultado de acordo com os filtros gerados de ano e produto. Foi criado filtros automaticos de acordo com o que for selecionado pelos filtros avançados, gerando assim, os valores de faturamento de cada vendedor, vendas por região, formas de pagamento e mais.
